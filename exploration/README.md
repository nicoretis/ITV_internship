## Simulation and Trait Analysis Project

This repository contains Quarto analyses and scripts related to population simulations under different plasticity scenarios and the study of trait variability.

Files and Descriptions

- plots folder
Contains all the plots generated by the Quarto Notebook

- Age_of_death.qmd
Runs the Early Plasticity and Plasticity scenarios 10 times each and plots the age of death of the animals as histograms.

- Coeff_variation_v1.qmd
Obsolete analysis. An early attempt to compute the coefficient of variation using only immutable traits. It is no longer functional but retained for reference.

- Coeff_variation_v2.qmd
Quarto analysis comparing the coefficient of variation and the counts of extinct simulations between Early Plasticity and Plasticity traits.

- Coeff_variation_v3.qmd
Advanced analysis of population stability, including the Mixed Plasticity scenario, where traits are updated by 50% each year.

- Equilibrium_at_zero.qmd
Adjusts the intercept parameter of the trait–demography relationship to ensure population stability at a constant 0 °C, satisfying the assumption that 0 is a neutral temperature.

- Plots_coff_talk.qmd
Contains quarto notobook that generates informative plots to illustrate and understand intraspecific trait variability.
